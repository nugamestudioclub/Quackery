## Initial setup

### Install unity hub
- Windows/Mac: https://docs.unity.com/en-us/hub/install-hub-win-mac
- Linux: https://docs.unity.com/en-us/hub/install-hub-linux

### Install unity 6.3 LTS
- Open Unity Hub
- Click on "Installs" on the left side
- Click "Install Editor" on the top right
- Pick "Unity 6.3 LTS" and wait for it to install

### Clone git repository
- Use the command line: "git clone git@github.com:Max-Selby/ParkourGame.git"
- Or use GitHub desktop (Open https://github.com/Max-Selby/ParkourGame, click "Code", then "Open with GitHub Desktop")
- If you need help with this let me know

### Open project
- Click on "Projects" on the left side of Unity Hub
- Click "Add" or "Add project from disk"
- Select the folder you cloned the repository into (It should contain Assets/ Packages/, etc.)
- Unity should recognize it as an existing project
- Open the project, and you're done!
